# Sulaiman Qazi Personal Site

Personal portfolio for Sulaiman Qazi, a Computer Science student at the University of Waterloo.

**Live site:** [sulaimanq.com](https://sulaimanq.com/)

## Built with

- HTML
- CSS
- JavaScript
- Canvas

No build step or framework is required.

## Run locally

Open `index.html` directly, or start the included PowerShell server:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Then visit [http://localhost:8123](http://localhost:8123).

## Project structure

```text
index.html
assets/
  css/
  fonts/
  img/
  js/
serve.ps1
```

The site is deployed on Cloudflare Pages.
